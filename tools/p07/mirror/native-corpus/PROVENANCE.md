The historical `3698` record-file / `8968` transaction values were observed
locally while preparing P07-11E. They were not produced by CI run
`30322277799`: that workflow did not execute `:test-clients:test`, uploaded no
artifacts, and retained no record-stream manifest. Two later clean executions
at the same source boundary produced different totals (`3668/8904` and
`3639/8841`). The old totals are therefore historical observations, not a
reproducible corpus contract.

run at `689e32ac70db7484fc43b7dbac178c4ffbb710df`:

       hedera-node/test-clients/build/hapi-test
./gradlew :test-clients:cleanTest :test-clients:test --no-daemon
